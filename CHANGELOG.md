# История изменений

## 1.0.0

- Полный пакет для Маркета дополнений: `dist/icons.tgz`, `modinfo.json`, `module.xml`, `install.php`, документация и тесты.
- Локальный слой Font Awesome Free 7.3.1 без внешних запросов: четыре woff2-шрифта и CSS.
- Модуль `icons` со страницей `?action=icons`: включение групп `core`, `devices`, `modules`, `admin` и выбор конкретных модулей.
- Генерация `cms/icons/icons-enabled.css` только с включёнными группами.
- Словари en/ru/ua; `uk.php` — тонкий алиас `ua.php`.
- Идемпотентная установка: подключение CSS в `common_header.html` добавляется один раз, `uninstall()` корректно его убирает.
- `template-icons.patch` с примерами недостающих пиктограмм.
- Снимки экрана из Docker-стенда и тесты генерации CSS/состава архива.
