# История изменений

## 1.1.0

- Синхронизация `fontawesome-compat.css` с исправленной версией ядра (`8e220311`): 65 сопоставленных классов, `content: ... !important`, только сопоставленные `glyphicon-*` получают Font Awesome; остальные сохраняют штатный шрифт.
- `icons_build_css()` не добавляет `@import` compat CSS, если ядро уже подключает его в `common_header.html`.
- Группа устройств переведена на актуальные классы шаблонов (`light-sensor`, `power-sensor`, `current-sensor`, `voltage-sensor`, `group_state`, `general-sensor`) и больше не перекрывает собственный `background-image` в `style`.
- Цвета иконок модулей и админки используют токены ядра `--mj-color-*` и `--mj-widget-icon-*` с fallback-значениями.
- `template-icons.patch` помечен устаревшим: правки разметки уже включены в ядро.
- Расширены тесты: отсутствие дублирующего `@import`, совместимость только для сопоставленных классов, актуальные классы устройств.

## 1.0.0

- Полный пакет для Маркета дополнений: `dist/icons.tgz`, `modinfo.json`, `module.xml`, `install.php`, документация и тесты.
- Локальный слой Font Awesome Free 7.3.1 без внешних запросов: четыре woff2-шрифта и CSS.
- Модуль `icons` со страницей `?action=icons`: включение групп `core`, `devices`, `modules`, `admin` и выбор конкретных модулей.
- Генерация `cms/icons/icons-enabled.css` только с включёнными группами.
- Словари en/ru/ua; `uk.php` — тонкий алиас `ua.php`.
- Идемпотентная установка: подключение CSS в `common_header.html` добавляется один раз, `uninstall()` корректно его убирает.
- `template-icons.patch` с примерами недостающих пиктограмм.
- Снимки экрана из Docker-стенда и тесты генерации CSS/состава архива.
