# Лицензии

## Код пакета

Код этого репозитория распространяется по лицензии **MIT**.

## Font Awesome Free 7.3.1

Пакет содержит локальную копию Font Awesome Free:

- **Иконки (SVG/CSS):** Creative Commons Attribution 4.0 License (CC BY 4.0) — <https://creativecommons.org/licenses/by/4.0/>;
- **Шрифты (woff2):** SIL Open Font License 1.1 — <https://scripts.sil.org/OFL>;
- **Код (CSS/SCSS/JS):** MIT License — <https://opensource.org/licenses/MIT>.

Автор Font Awesome — @fontawesome, <https://fontawesome.com>.

Атрибуция: в файле `src/3rdparty/fontawesome/css/all.min.css` сохранён оригинальный заголовок с указанием версии и лицензии. При распространении пакета этот заголовок удалять нельзя.
