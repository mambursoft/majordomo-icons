# Установка

## Требования

- MajorDoMo на ветке `alpha` (проверено на `0db4d9a`);
- PHP 7.3 или новее (проверено на 7.3 и 8.2);
- доступ на запись к `cms/`, `templates/`, `css/`, `3rdparty/`, `languages/`, `modules/`.

Пакет не требует интернета: все шрифты и CSS лежат внутри архива.

## Маркет дополнений

1. Соберите архив: `powershell -ExecutionPolicy Bypass -File build_package.ps1`.
2. Положите `dist/icons.tgz` в `cms/saverestore/` (имя можно произвольным, но расширение `.tgz` обязательно).
3. В панели управления откройте **Маркет → Установить из файла**, выберите архив.
4. MARKET распакует архив, выполнит `install.php` и скопирует файлы в корень MajorDoMo.
5. Откройте `?action=icons`.

## Ручная установка

```bash
cd /path/to/majordomo
tar -xzf icons.tgz -C .
php install.php
```

`install.php` делает следующее:

- регистрирует модуль `icons` в `project_modules`;
- добавляет модуль в `ACCESS` текущего администратора;
- создаёт `cms/icons/config.json` и `cms/icons/icons-enabled.css`;
- дописывает подключение CSS в `templates/common_header.html` с маркером `<!-- majordomo-icons:enabled-css -->`.

Повторный запуск безопасен: подключение добавляется только один раз.

## Проверка после установки

1. Очистите кэш браузера.
2. Откройте главную страницу и панель управления — глифы должны отображаться без запросов к внешним CDN.
3. Откройте `?action=icons`, включите нужные группы и нажмите **Сохранить и пересоздать CSS**.
4. В консоли браузера не должно быть 404 по путям `/3rdparty/fontawesome/webfonts/`.
