# Настройка

Страница модуля: `admin.php?action=icons`.

## Группы

| Группа | Что делает | Когда включать |
|---|---|---|
| `core` | Подменяет семейство шрифта и коды для классов `glyphicon-*` | Всегда — это базовый слой совместимости |
| `devices` | Красивые цветные иконки для «Простых устройств» | Если используются плитки `device-icon` |
| `modules` | Глифы вместо `img/modules/*.png` | Если需要处理 только некоторые модули — отметьте их списком |
| `admin` | Глифы вместо `ico_*.gif` | Для старых служебных значков в админке |

## Сохранение

После нажатия **Сохранить и пересоздать CSS**:

1. `cms/icons/config.json` получает выбранные группы и модули;
2. `cms/icons/icons-enabled.css` пересоздаётся из четырёх исходных CSS;
3. в файл попадают только включённые `@import` и правила выбранных модулей.

Пример сгенерированного файла:

```css
/* MajorDoMo icons: сгенерировано интерфейсом ?action=icons */
@import url("../../css/fontawesome-compat.css");
@import url("../../css/fontawesome-module-icons.css");
.fa-module-icons a[href*="action=devices"]::before { content: "\f2db"; --fa-icon-color: #e67e22; }
```

## Подключение классов

Сгенерированный CSS уже подключён в `common_header.html`. Для групп, которые работают через префикс класса, добавьте класс на контейнер:

```html
<div class="fa-module-icons">…меню модулей…</div>
<div class="fa-devices">…плитки устройств…</div>
<div class="fa-admin-icons">…служебные ссылки…</div>
```

Группа `core` не требует дополнительных классов: она меняет существующие `glyphicon-*`.
